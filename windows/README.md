# EUGENE AI

Eugene AI is an AI model based on an LLM of your choice.

There are 2 versions of Eugene AI:

- Windows
- Linux (Ubuntu, Debian) — NOT READY YET. I WILL ADD TO THE REPO ONCE DONE.

This AI would be more advanced, but I don't really want to buy API keys, so I just made my own commands in `commands.py`.

## How to Install

1. Download the zipped files from the Releases tab.
2. Build it yourself.

## How to Use

Run the program and Eugene is ready.

It doesn't have to be Eugene. You can customize the personality of the AI in `persona.txt` and the name in `config.py`.

The AI may be dumb, but it all depends on the hardware you have.

This project is using the lightweight `llama3.1:8b` model.

I would implement image generation and a GUI, but I don't want to.

## Required Installs

- Ollama
- Python
- PyAutoGUI
- AppOpener
